# Aplicativo Android da Shekinah

Este aplicativo abre a versão publicada do Centro de Ensino Shekinah em
`https://site-shekinah.kuadmff2.workers.dev`.

O APK de teste é gerado automaticamente pelo fluxo **Gerar APK da Shekinah**
na aba **Actions** do GitHub. Depois que a execução terminar, abra a execução e
baixe o arquivo **Shekinah-APK** na seção **Artifacts**.

O arquivo mais recente também fica disponível diretamente em:

`https://github.com/kuadmff2-bit/Site_shekinah/releases/download/aplicativo-shekinah/Shekinah.apk`

Como o conteúdo vem do endereço publicado, atualizações feitas no site aparecem
no aplicativo sem exigir um novo APK. Um novo APK só é necessário quando o
código Android, ícone, nome ou permissões do aplicativo forem alterados.
